## What Is CafeTran Espresso

CafeTran Espresso is a local Windows CAT helper for translation projects you already keep. It gives you a named cafe desk, a short memory list, and a segment view that points back to the same file. It does not try to own every window on the PC. It sits beside the memories you already use and holds only the project that is open now.
The idea behind CafeTran Espresso own projects is small on purpose: one desk, one list, one path back. Extra memories wait for their own title. CafeTran Espresso starts with a local profile and does not need a complex account system.
People who keep a client job they already own, a memory they already administer, or a segment set they already keep use CafeTran Espresso cafe desk in different ways, but the job stays the same. Untitled copies leave the live set. The last handoff stays on the project you keep.

## Starting with CafeTran Espresso

Prerequisites: A PC you own, translation files you already keep, and permission to open a local helper.

1. **Prepare:** Close leftover untitled memories and open the last CafeTran Espresso session on a project you keep.
2. **Configure:** Read the cafe desk and the memory list, then drop anything that belongs to a different job.
3. **Test:** Finish one visible segment view inside CafeTran Espresso own projects.
4. **Refine:** Write what changed, then close with a shorter memory list than you found.
5. **Apply:** Keep CafeTran Espresso cafe desk on the same file during the next session.
6. **Maintain:** If the desk feels crowded, leave extra memories off the live set.
7. **Keep:** Leave CafeTran Espresso cafe desk on a project you already own.
8. **Scope:** If a memory is not yours, leave it off the live list.
